* React.js frontend : (où tu consommes l’API avec axios pour afficher les infos liées). 1. Le rôle d’un Model en Laravel


✅ Donc, pour résumer :

* hasMany = "un → plusieurs"

* belongsTo = "plusieurs → un"

* belongsToMany = "plusieurs ↔ plusieurs (table pivot)"

* hasOne = "un → un"

👉 Quelques exemples :

* $table → pour préciser le nom de la table (si ce n’est pas le pluriel automatique du Model). 

* $primaryKey → pour préciser la clé primaire.

* $incrementing → pour dire si la clé est auto-incrémentée.

* $keyType → pour préciser le type de la clé (string ou int).

* $fillable → liste des colonnes qui peuvent être insérées en mass assignment.

* $hidden → colonnes qu’on veut cacher lors d’un retour JSON.

* $casts → pour transformer automatiquement des colonnes en types (datetime, boolean, etc.).

* Un Model est une classe qui représente une table dans la base de données.

* Le fichier Personne.php correspond à la table personnes.

* Le fichier Inscription.php correspond à la table inscriptions.

Chaque Model sert à :
✅ définir la table (protected $table)
✅ définir la clé primaire (protected $primaryKey)
✅ gérer les colonnes modifiables ($fillable)
✅ déclarer les relations entre les tables (avec belongsTo, hasMany, etc.)

Parfait 👍 je vais te montrer **le lien entre :**

* le **Model** (où tu définis la relation)
* le **Controller** (où tu appelles cette relation pour charger les données)
* le **React.js frontend** (où tu consommes l’API avec axios pour afficher les infos liées).

---

## 🔹 1. Dans le **Model** (Laravel Eloquent)

Dans `Inscription.php` :

```php
public function personne()
{
    return $this->belongsTo(Personne::class, 'matricule', 'matricule');
}
```

👉 Ici, tu dis à Laravel :

* Une **Inscription appartient à une Personne** (clé étrangère = matricule).

---

## 🔹 2. Dans le **Controller**

Exemple : `InscriptionController.php`

### a) Charger inscription **sans relation**

```php
public function index()
{
    return Inscription::all(); 
}
```

👉 Ça te renvoie uniquement les champs de la table `inscriptions`.

### b) Charger inscription **avec la personne liée**

```php
public function index()
{
    return Inscription::with('personne')->get();
}
```

👉 Résultat JSON :

```json
[
  {
    "no_inscrit": 1,
    "matricule": "P001",
    "date_inscrit": "2025-10-01",
    "anneesco": "2025-2026",
    "personne": {
      "matricule": "P001",
      "nom": "Rakoto",
      "prenom": "Jean",
      "sexe": "Homme",
      "adresse": "Antananarivo"
    }
  }
]
```

💡 Grâce au `with('personne')`, chaque inscription renvoie aussi les infos de la **personne liée**.

## 🔹 3. Dans le **React.js frontend**

Avec Axios :

```jsx
import React, { useEffect, useState } from "react";
import axios from "axios";

function ListeInscriptions() {
    const [inscriptions, setInscriptions] = useState([]);

    useEffect(() => {
        axios.get("http://localhost:8000/api/inscriptions")
            .then(res => setInscriptions(res.data))
            .catch(err => console.error(err));
    }, []);

    return (
        <div className="container mt-4">
            <h2>Liste des inscriptions</h2>
            <table className="table table-bordered">
                <thead>
                    <tr>
                        <th>N° Inscription</th>
                        <th>Date</th>
                        <th>Année scolaire</th>
                        <th>Matricule</th>
                        <th>Nom</th>
                        <th>Prénom</th>
                    </tr>
                </thead>
                <tbody>
                    {inscriptions.map((insc) => (
                        <tr key={insc.no_inscrit}>
                            <td>{insc.no_inscrit}</td>
                            <td>{insc.date_inscrit}</td>
                            <td>{insc.anneesco}</td>
                            <td>{insc.matricule}</td>
                            {/* ⚡ On accède aux données liées */}
                            <td>{insc.personne?.nom}</td>
                            <td>{insc.personne?.prenom}</td>
                        </tr>
                    ))}
                </tbody>
            </table>
        </div>
    );
}

export default ListeInscriptions;
```

---

## 🚀 Résumé

* **Dans le modèle** : tu définis la relation (`belongsTo`, `hasMany`, …).
* **Dans le controller** : tu utilises `with('relation')` pour charger la relation et renvoyer en JSON.
* **Dans React** : tu consommes le JSON → tu peux accéder directement aux infos liées (`insc.personne.nom`).

// HistogramSalaireStats.js
import React, { useEffect, useState } from 'react';
import axios from 'axios';
import {PieChart, Pie, Cell, Tooltip, Legend, ResponsiveContainer} from 'recharts';

const HistogramSalaireStats = () => {
  const [stats, setStats] = useState(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    axios.get('http://localhost/vue-js/api/index.php?stats=1')
      .then(res => {
        setStats(res.data);
        setLoading(false);
      })
      .catch(err => {
        console.error("Erreur lors du chargement des stats :", err);
      });
  }, []);

  if (loading || !stats) return <p>Chargement...</p>;

  const data = [
    { name: 'Minimum ', value: parseFloat(stats.salaire_min) },
    { name: 'Maximum ', value: parseFloat(stats.salaire_max) },
    { name: 'Total ', value: parseFloat(stats.salaire_total) },
  ];


  const colors = ['#cd2929ff', '#dbb417ff', '#0cb012ff'];


  return (
    <div style={{ marginTop: '10%' }} className='row'>

      <div className='col-md-12'>
        <h3 style={{ textAlign: 'center' }} className='text-white'>Répartition des Salaires en PieChart</h3>
        <ResponsiveContainer width="100%" height={400}>
          <PieChart>
            <Pie data={data} dataKey="value" nameKey="name" cx="50%" cy="50%"  outerRadius={window.innerWidth > 768 ? 180 : 120}fill="#8884d8" label >
              {data.map((entry, index) => (
                <Cell key={`cell-${index}`} fill={colors[index % colors.length]} />
              ))}
            </Pie>
            <Tooltip />
            <Legend />
          </PieChart>
        </ResponsiveContainer>
      </div>
    </div>
  );
};

export default HistogramSalaireStats;
